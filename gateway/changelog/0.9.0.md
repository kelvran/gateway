# gateway v0.9.0 — 2026-09-11

Entries below are frozen as of this release — see `unreleased.md` for anything added since. [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) categories; [SemVer](https://semver.org/) — load-bearing for the Go module path/tag.

## Added

- Gemini cache-token read-side extraction: `adapter.Usage.CacheReadTokens` now populated from `usageMetadata.cachedContentTokenCount` (implicit, on-by-default caching), on both the buffered and streaming paths.
- `claude-fable-5-1` price-table example in `config.example.yaml`, demonstrating Anthropic's real 0.025x cache-read pricing tier for that model (vs. the standard 0.1x).
- A design-only RFC for a Redis-backed L1(local)/L2(shared) cache — no code; deliberately deferred pending the already-built cross-instance-telemetry evidence trigger.
- A fault-injection test harness (`faultinjection_test.go`) proving fallback chains, the per-request circuit breaker, and inter-hop backoff behave as designed under an injected fault, through the live `HandleChatCompletion` pipeline.

## Changed

- `openaicompat`'s runtime-support doc comment tightened from a blanket "runtime-dependent, unverified" caveat to the real, source-grounded per-runtime split (vLLM/Ollama/llama.cpp genuinely support cache-token reporting; TGI does not).

## Fixed

- Go toolchain bumped `1.25.0` → `1.26.8` after `govulncheck` found 6 real reachable stdlib CVEs, root-caused to Go 1.25 being past its supported-version window (Go supports only the latest 2 major releases).

## Security

- Regression test proving pre-call Guardrails already scan `role:"tool"` messages representing a tool-call result fed back from an earlier turn — no production code change needed (`serializeMessages`'s existing role-agnostic full-marshal design already covers it).
- `govulncheck` dependency-CVE scanning wired into CI for the first time.
- `## NIST AI 600-1 Crosswalk` section added to `THREAT_MODEL.md`, naming two real, previously-undocumented content-moderation gaps (Dangerous/Violent/Hateful Content; Obscene/Degrading/Abusive Content) with no existing mitigation.
