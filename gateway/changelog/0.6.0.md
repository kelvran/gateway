## Fixed

- Bounded JSON-Schema nesting-depth (32 levels) and total-token-count (10,000) on `ChatRequest.ResponseFormat.JSONSchema.Schema`, closing a request-shaped complexity/DoS gap underneath the existing whole-body size cap — checked via a streaming token scan, never a full unmarshal first. Added the missing dataplane-level end-to-end test proving a first-attempt call to a Bedrock model outside the structured-output allowlist correctly omits `additionalModelRequestFields`.

## Security

- Reconciled `THREAT_MODEL.md`/`SECURITY.md` with round-3 features (structured-output normalization, prompt management) that had shipped without updating either doc: named the JSON-Schema depth/complexity gap (fixed above), prompt-management's global (not tenant-scoped) design against the existing cross-tenant threat class, and Bedrock's first-attempt structured-output omission as a tested, accepted v1 limitation. Added a regression test proving `PromptVariables`-injected PII/secrets are already caught by the existing pre-call Guardrails check.
