## Fixed

- The openai and openaicompat streaming decoders never forwarded a mid-stream refusal fragment (`streaming.MessageDelta.Refusal`) -- the buffered path already surfaced a model's real refusal message, but the streaming counterpart silently dropped it. Confirmed against OpenAI's own official openai-openapi spec: `ChatCompletionStreamResponseDelta` genuinely carries `refusal` as a field sibling to `content`/`role`/`tool_calls`, streamed incrementally like ordinary content.

## Security

- Suppressed a confirmed false-positive OpenSSF Scorecard vulnerability finding (`GO-2026-5932`, `golang.org/x/crypto/openpgp`) via `gateway/osv-scanner.toml` -- the flagged subpackage is never imported anywhere in this codebase, and `govulncheck`'s real call-graph analysis independently confirms zero reachable vulnerabilities.
