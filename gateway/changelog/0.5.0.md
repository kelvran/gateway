# gateway v0.5.0 — 2026-09-15

Entries below are frozen as of this release — see `unreleased.md` for anything added since. [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) categories; [SemVer](https://semver.org/) — load-bearing for the Go module path/tag.

## Added

- Added cross-provider structured-output/JSON-schema normalization: a new canonical `ChatRequest.ResponseFormat` (plus `ToolDef.Strict` for Anthropic), translated per-adapter into each provider's native mechanism (OpenAI `response_format`, Anthropic `output_config.format`, Gemini `response_schema`/`response_mime_type`, and — for a live-verified allowlist of Bedrock-hosted Claude models — `additionalModelRequestFields`, the first use of that escape hatch in this codebase). Multi-hop fallback chains now skip a target that can't honor a request's required output shape rather than routing to it blindly.
- Added server-side prompt/template management: operator-managed, versioned prompt templates (`prompt_id`/`prompt_version`/`prompt_variables`), resolved at the gateway into real message content, with new Admin API CRUD routes. Prompts are global, not tenant-scoped — the same category as `price_table`/`deployments`/`guardrails config`.
