## Fixed

- `buf breaking`'s main-branch comparison in CI failed on any tag-triggered run (e.g. a real release tag): `actions/checkout` leaves only `refs/remotes/origin/main` on a detached tag checkout, not the `refs/heads/main` buf's git resolver needs. Fixed with an explicit `git fetch --update-head-ok origin main:refs/heads/main` step, idempotent on ordinary branch-push runs too.
