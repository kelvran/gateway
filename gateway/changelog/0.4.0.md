# gateway v0.4.0 — 2026-09-10

Entries below are frozen as of this release — see `unreleased.md` for anything added since. [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) categories; [SemVer](https://semver.org/) — load-bearing for the Go module path/tag.

## Added

- Added TTL jitter (on by default, 10%) to the L1/L2/L3 in-process caches: a burst of entries written together (e.g. after a deploy) previously expired in near-lockstep — a real thundering-herd risk. Additive-only, operator-tunable via new `cache.jitter_fraction`/`l2.jitter_fraction`/`l3.jitter_fraction` config keys; the pre-existing deterministic-testing constructor (`NewWithClock`) stays byte-for-byte zero-jitter.
- Added `kelvran.cache.savings_usd`, a new OTel metric (Float64Counter, dimensioned by cache layer) reporting the notional dollar cost saved by every cache hit — the exact per-request data was already computed and emitted, this closes the missing aggregation piece so an operator's own Prometheus/Grafana can sum/graph it directly.

## Fixed

- Fixed a real cost-accounting defect: the Anthropic and Bedrock adapters silently dropped the providers' cache-token usage fields, undercounting real dollar cost, per-key budget spend, and TPM rate-limit usage on every cached request — the default path since provider-side prompt caching shipped default-on. `adapter.Usage.PromptTokens` is now cache-inclusive by definition, fixing every downstream consumer automatically; an unset per-model cache price now falls back to that model's ordinary prompt-token rate rather than $0.
