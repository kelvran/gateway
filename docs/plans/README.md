# Plans — engineering record, not user documentation

Task-by-task execution plans from the project's first days (2026-09-02 to 2026-09-04), each naming the RFC it implements and listing the files it intended to change. They record what was planned, not what shipped: several describe edits to files that were later restructured or replaced.

Planning did not stop here; it moved. Decisions with their rationale are dated entries in [`DECISIONS.md`](../../DECISIONS.md); research reports with ranked proposals live under [`docs/upgrade-research/`](../upgrade-research/README.md); each work session's "Next steps / resume point" is the tail of [`docs/agents/LOGS.md`](../agents/LOGS.md). For what the gateway does today, start at [`docs/README.md`](../README.md).
