## Added

- Added `evals audit-corpus --suite PATH [...] --out PATH`, a static-mode benchmark-corpus audit tool: runs a real LLM audit pass over regression-corpus cases, flagging design defects (ambiguous task framing, wrong/unverifiable ground truth, environment/tooling conflicts). Report-only, never a `--fail-under`-style gate — findings are for a human to review. Defaults to Claude Sonnet 5, not the panel's usual Haiku default.
