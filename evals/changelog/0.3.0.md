# evals v0.3.0 — 2026-09-09

Entries below are frozen as of this release — see `unreleased.md` for anything added since. [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) categories; [SemVer](https://semver.org/) by default.

## Added

- Added a real judge-accuracy metric: `report --judge-accuracy PATH`, only meaningful together with `--scores`, joins persisted `Score`s to a fixture's new structured `task_spec.expected_verdict` ground-truth field by `(eval_case_id, eval_case_revision)` and prints Cohen's kappa plus a full confusion matrix per `scorer_type`, in addition to (never replacing) the existing pass-rate/CI line — never affects `--fail-under` gate semantics. New pure `evals.stats.confusion_matrix`/`cohens_kappa` functions. All 24 cases in the existing judge-accuracy regression corpus got a hand-derived `expected_verdict: true|false|null` label from their own existing case notes.
- Added quote-grounded verdicts, measurement-only: both judge prompt templates now require a `QUOTE: <verbatim quote>` line before the verdict, and `JudgeResult`/`PanelVote`/`Score` all gain a `quote_grounded` field (a panel's is an AND-aggregate across its votes), surfaced as a new non-gating `(quote_grounded: G/N)` note in `report`. Backward-compatible by construction — a response with no `QUOTE:` line (an older format, or a pre-existing cached response) still parses correctly, just reports `quote_grounded=False`. Enforcement (discarding an ungrounded vote) is deliberately deferred pending real data on how often grounding fails for this judge/panel.
- Added opt-in same-vendor prompt-debiasing: a new `--judge-debias` flag on `run`/`rollout` makes each LLM-judge call twice — reference-first, then candidate-first — combining fail-closed on disagreement (marked `[POSITION DISAGREEMENT — fail-closed]` in the persisted rationale, never silently resolved). Off by default: doubles judge-call cost/latency for a single unreplicated preprint finding. The two calls are made strictly sequentially (never concurrently) to avoid racing on the shared per-call cost side channel every judge provider exposes.
