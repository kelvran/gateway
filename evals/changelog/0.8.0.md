# evals v0.8.0 — 2026-09-11

Entries below are frozen as of this release — see `unreleased.md` for anything added since. [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) categories; [SemVer](https://semver.org/) by default.

## Added

- Documented the regression corpus's real "GAP" convention (`ARCHITECTURE.md`): when a case tracks a real, currently-unfixed defect, `reference` holds the ideal/target behavior while `task_spec["output"]` holds the honest current-state FAIL — including two lookalikes it must not be confused with.
- `evals/field_swap_lint.py` (new, CI-gating): detects the exact guardrail-13/18 transposition bug class via a pure `reference`/`output` value-swap signature between two cases.
- `evals/corpus_staleness.py` (new, report-only) and a new `evals check-corpus-staleness` CLI command: a `verified_against` citation parser (handling the real "carried-over filename" shorthand) that flags citations whose cited file was touched more recently than the corpus case citing it.
