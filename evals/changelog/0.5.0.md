# evals v0.5.0 — 2026-09-15

Entries below are frozen as of this release — see `unreleased.md` for anything added since. [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) categories; [SemVer](https://semver.org/) by default.

## Added

- Added a persisted, trended, side-by-side history of judge-quality signals: judge-accuracy kappa, quote-grounding rate, audit-corpus defect rate, and cost, each its own named series, never fused into a composite score. New opt-in `--record-trend PATH` on `report`/`audit-corpus`, and a new `evals trend show` command to read the history back.
- Added `evals flag-candidates --suite PATH --results PATH [--out PATH]`: a rule-based auto-flag pass over ingested `drift_sample` cases, surfacing promotion candidates (and the exact `evals promote` command to run) for the still-fully-human-triggered `evals promote` — never a new, automated promotion path.
